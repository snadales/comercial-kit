# comercial-kit
Estándar común K1–K7 para servicios comerciales Navarino
- Estructura según `homelab/proyectos/convencion-repos-dev` §12 (`repo-orden auditar` la verifica). Lo obsoleto va a `_archive/`, no se borra.
- Carpetas de dominio nuevas: siguiente número libre, sin reordenar ni reutilizar números.

## Reglas comunes
- Responder y commitear en español. Secretos solo como `op://IA/<item>/<campo>`.
- Documentación de infraestructura solo en la wiki (wiki.yarken.cl); consultar `yarken-docs` antes de adivinar.
- Un issue de GitHub por tema, con atribución de agente/modelo (`~/bin/gh-issue`).
